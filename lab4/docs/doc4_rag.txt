Retrieval-augmented generation combines a retrieval system with a language model so that answers are grounded in an external document store rather than the model's fixed training weights. A corpus is first split into overlapping chunks, and each chunk is embedded into a vector using a scheme such as TF-IDF or dense sentence embeddings. At query time, the question is embedded with the same scheme and compared against every chunk using a similarity measure, and the top-k most similar chunks are retrieved. Those chunks are pasted into a prompt as evidence, along with an instruction to answer using only the supplied context, which lets the final answer cite the exact source chunk it came from. Because the corpus lives outside the model, it can be updated at any time without retraining, and answers can be checked against the retrieved text for accuracy.
