Breadth-first search explores a graph level by level, using a FIFO queue to hold the frontier of unvisited nodes. It guarantees the shortest path in terms of number of edges when every edge has the same cost. The algorithm marks each node as visited the first time it is reached, so the first path found to any node is provably the shortest one possible. Breadth-first search expands every node at the current depth before moving to the next depth, which is why it never has to revise a shortest-path decision once it has been made.
