Uniform-cost search generalises breadth-first search to graphs where edges carry different costs. It replaces the FIFO queue with a priority queue ordered by the accumulated path cost from the start node. A node is only finalised when it is popped from the priority queue, at which point its cost is guaranteed to be minimal, because any cheaper path would have been popped earlier. Uniform-cost search reduces to breadth-first search exactly when every edge cost is equal to one.
