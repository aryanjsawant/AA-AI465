Reading the table: at p = 0 the memoryless agent is dominated - it
pays -1 for ever.  As p grows, patrolling starts to pay for itself,
because a square the agent never revisits cannot be cleaned.  The
agent that only *believes* the world is clean is the one that fails:
its model is correct when written and wrong one step later.  Note
also that the do-nothing agent beats the reflex agent at small p:
the reflex agent is not rational there either, because it pays to
move without weighing that cost against the chance of finding dirt.
